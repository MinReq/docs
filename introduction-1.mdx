Build global communications with phone numbers, voice, SMS, cloud PBX tools, API automation, and integrations.

DIDWW is used by businesses, operators, service providers, and communication platforms to create reliable voice and messaging services across multiple countries. It helps teams manage phone numbers, route calls, send messages, automate provisioning, and connect communications workflows to their own systems.

<Columns cols={3}>
  <Column>
    ### Global numbers

    Buy, port, manage, and configure DID numbers for local, national, mobile, toll-free, shared-cost, and UIFN use cases.
  </Column>
  <Column>
    ### Voice and messaging

    Route inbound and outbound voice traffic, configure SIP trunking, and use SMS services where supported.
  </Column>
  <Column>
    ### Automation and integrations

    Use API, call events, and integrations to connect communications services with your systems, PBXs, CRMs, or AI platforms.
  </Column>
</Columns>

## What you can achieve

<Tabs>
  <Tab title="Manage numbers">
    Use DIDWW to buy numbers, transfer existing numbers, manage assigned numbers, configure capacity, and apply reusable configuration profiles.

    - [Phone Numbers](/phone-numbers) — Buy, port, manage, and configure DID numbers.
    - [Buy Numbers](/phone-numbers/buy-numbers) — Search available numbers and complete an order.
    - [My Numbers](/phone-numbers/my-numbers) — Review and manage assigned numbers.
    - [Number Porting](/phone-numbers/number-porting) — Transfer existing numbers to DIDWW.
  </Tab>
  <Tab title="Route calls">
    Use DIDWW to deliver inbound calls to your infrastructure, configure outbound SIP trunking, and support number-based voice services.

    - [Voice](/voice) — Configure DIDWW voice services.
    - [Inbound Trunks](/voice/inbound-trunks) — Route inbound calls to SIP, PSTN, or trunk groups.
    - [Outbound Trunks](/voice/outbound-trunks) — Configure outbound SIP trunking and termination.
    - [Emergency Calling](/voice/emergency-calling) — Configure emergency calling for supported DID numbers.
  </Tab>
  <Tab title="Build call flows">
    Use phone.systems™ to build cloud PBX call routing with users, contact methods, schedules, voicemail, recording, queues, menus, and app-based calling.

    - [Cloud Phone System](/phone-systems) — Build and manage call routing with phone.systems™.
    - [Call Flows](/phone-systems/Call-flows) — Create visual routing flows.
    - [Users](/phone-systems/Users) — Manage users and app devices.
    - [phone.systems™ App](/phone-systems/app) — Configure and use the softphone app.
  </Tab>
  <Tab title="Automate">
    Use developer tools and integrations to automate provisioning, retrieve operational data, and connect DIDWW services to external systems.

    - [API Documentation](/api3) — Automate DIDWW services with the API.
    - [Call Events](/call-events) — Use real-time call events for tracking and automation.
    - [Integrations](/integrations) — Connect DIDWW with PBXs, AI platforms, and automation tools.
  </Tab>
